# Supermarket_Sales_Prediction (Machine Learning)
In this project, we employ the XGBoost Regressor, a robust and efficient machine learning algorithm, to predict supermarket sales. XGBoost (eXtreme Gradient Boosting) is a gradient-boosting framework known for its scalability, speed, and performance on structured data.The XGBoost Regressor is chosen due to its High Predictive Power i.e. Its ability to capture complex relationships between features and target variables.
By training the XGBoost model on labeled sales data , we aim to achieve an optimal balance between bias and variance, resulting in accurate and actionable predictions for supermarket sales.
